## Findings per principle

### I. Performance And Memory First: no violation
- Inputs borrowed in place (FR-003, spec.md:325-329); environment created once and reused (FR-007,
  User Story 2); results written by the backend into caller arrays (FR-006, User Story 2

  per-cone descriptor list, whose size the plan must state (FR-003). SC-002 caps extra heap at 4 KiB.

  maintainer decision 19.

- Two tiers: unlicensed validation, error-code, panic and version tests run everywhere; licensed

  for every instance and backend (FR-014, spec.md:386-388).
- Frozen corpus: toy instances and `iDopaNeuroC_problem_LP` are declared in project.yml:74-118.
- Failing-input tests before any solver call (User Story 5 scenario 1; SC-006).
- Tolerances justified by the solver's own tolerances: the comparison rule (spec.md:95-117) uses the

  equality only reported, not required.

  instance with dimensions and nonzeros, solver versions, N and statistic.
