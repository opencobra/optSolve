## Findings per principle

**I. Performance And Memory First: complies.**
- **Input path**: inputs are borrowed through `slice::from_raw_parts` without copying
  (plan.md:50-58; research R5).
- **Allocations**: the C layer allocates only the cone descriptor vector and the raw-parameter
  names (O(cones), O(raw parameters)). Result names are made lazily. Nothing is proportional to
  nnz.
- **NaN fill**: O(m + n + k) writes, listed in Complexity Tracking (plan.md:305).
- **Environment reuse**: this is the purpose of the handle (T012).
- **Output extraction cost**: measured with every accessor read (T017).
- **Configuration audit**: research R9 and R2. The only new parameter is `SoftMemLimit`, unset by
  default. Validation is not removed.

  an ignored trial naming the missing backend).
