# Project instructions

Read [the Spec Kit constitution](.specify/memory/constitution.md) before acting.
It is the single source of truth for project behaviour. Amend it through
`/speckit-constitution`.

Project-specific parameters (names, paths, branch roles, supported solver versions)
are declared once in [.specify/memory/project.yml](.specify/memory/project.yml).
Read values from there; never restate them, and never hard-code an absolute
repository path.
